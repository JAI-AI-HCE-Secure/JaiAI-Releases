# Jai AI official downloads

This public repository contains release binaries and their checksums for Jai AI Desktop and Jai AI Local Host. The application source code remains in the private `SecureChatGPT-Host` repository.

Download only the installer for your platform from [Releases](https://github.com/JAI-AI-HCE-Secure/JaiAI-Releases/releases). Verify its SHA-256 digest against the matching release checksum file before installation.

Desktop installers include the matching platform Local Host runtime. They do not include model weights, provider credentials, private keys, or the separately administered SecureChatGPTHost server and HSM deployment.

Windows packages are currently unsigned and may trigger a publisher or SmartScreen warning. macOS direct downloads are Developer ID signed and notarized. Availability of Mac App Store and Microsoft Store editions is tracked separately from these direct downloads.
